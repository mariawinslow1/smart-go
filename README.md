# REVIEW LAB — React-сайт

Многостраничная визитка для услуги анализа отзывов / Voice of Customer.

## Страницы

- `/` — Главная
- `/method` — Методика
- `/cases` — Демо-кейсы
- `/free-audit` — Бесплатный мини-разбор / контакт

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
```

## Перед публикацией обязательно

1. В `src/config.js` замените `hello@your-domain.example` на рабочий email.
2. Переименуйте `REVIEW LAB`, если выберете другое название.
3. Демо-кейсы помечены честно: не выдавайте их за реальных клиентов.
4. Когда появятся реальные кейсы, добавляйте результаты только с разрешения компаний и только подтверждённые цифры.
5. Рекламный блок уже предусмотрен флагом `showPartnerSlot`, но по умолчанию выключен — для экспертной визитки это выглядит дороже и надёжнее.

## Публикация

Проект использует React Router и `BrowserRouter`. На Vercel/Netlify/Cloudflare Pages нужно включить SPA fallback, чтобы маршруты `/method`, `/cases` и `/free-audit` открывались напрямую.

## Заметка о шрифтах

Сейчас шрифты подключены через Google Fonts. Если нужен полностью автономный сайт, замените их системным стеком или подключите лицензированные локальные веб-шрифты самостоятельно.
