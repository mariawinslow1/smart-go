# Maria Winslow — сайт аналитики клиентских отзывов

Многостраничный сайт независимой аналитической практики Maria Winslow. Сайт объясняет методику работы с клиентской обратной связью и конкурентным контекстом, показывает демонстрационные кейсы и принимает заявки на первичный разбор.

## Стек

- React 18
- Vite 5
- React Router 6
- Netlify Forms

## Локальный запуск

```bash
npm install
npm run dev
```

Vite выведет локальный адрес, обычно `http://localhost:5173`.

## Production-сборка

```bash
npm run build
npm run preview
```

Готовые файлы создаются в `dist/`.

## Маршруты

- `/` — главная
- `/method` — методика
- `/cases` — демонстрационные кейсы
- `/audit` — первичный разбор и форма
- `/privacy` — политика конфиденциальности
- остальные адреса — страница 404

Старый адрес `/free-audit` перенаправляется на `/audit`.

## Где менять содержимое

- Бренд, контакты, домен и SEO-метаданные: `src/config.js`
- Кейсы и таблица приоритетов: `src/pages/Cases.jsx`
- Тексты страниц: `src/pages/`
- Визуальная система и адаптивность: `src/styles.css`
- Статическая копия полей формы для Netlify: `index.html`

Перед публикацией заполните `email`, при необходимости `telegram`, и `siteUrl` в `src/config.js`. После указания `siteUrl` страницы будут получать canonical URL.

## Публикация на Netlify

1. Подключите Git-репозиторий в Netlify.
2. Build command: `npm run build`.
3. Publish directory: `dist`.
4. Выполните первый deploy и проверьте раздел Forms.
5. Укажите полученный домен в `siteUrl` файла `src/config.js` и опубликуйте снова.

`netlify.toml` и `public/_redirects` уже содержат SPA fallback для прямого открытия маршрутов React Router. Форма `primary-audit` подготовлена для Netlify Forms и начинает принимать заявки после публикации.

## Важное правило кейсов

Текущие примеры основаны на синтетических данных и явно отмечены как демонстрационные. Реальные результаты следует добавлять только с разрешения компаний и без неподтверждённых цифр.
