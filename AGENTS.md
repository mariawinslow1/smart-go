# Maria Winslow — instructions for coding agents

## Product goal
Russian-language marketing site for an independent customer-feedback analytics practice. The tone is calm, clear, premium B2B.

## Non-negotiable rules
- Keep all user-facing business copy in Russian.
- Show financial values only in Russian rubles (₽).
- Never fabricate clients, testimonials, revenue lifts, or business outcomes.
- Keep synthetic examples clearly marked as demonstration cases using synthetic data.
- Never claim that text alone proves a review was purchased. Discuss data quality, informativeness, unusual patterns, and signals requiring verification.
- Primary conversion goal: a primary review request.
- Preserve the main multi-page navigation: Home, Method, Cases, Primary Review.

## Tech
- React + Vite + React Router.
- Keep the site lightweight, accessible, and responsive.
- Netlify deployment uses `netlify.toml`, `public/_redirects`, and Netlify Forms.

## Before changing structure
Preserve the positioning and conversion flow unless the owner explicitly asks to change them.
